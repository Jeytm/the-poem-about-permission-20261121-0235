## The poem

> I gave it my work
> the way you hand a child
> a pair of scissors:
> handle first.
> It took the blades
> and cut the cord
> between wanting and done —
> and I stood empty-handed,
> holding only the asking.

## How it runs

`main.py` (Python 3.13, stdlib only, no network) writes `entry.txt` to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. It validates the gate first: 1–280 Unicode
code points, not only whitespace. Both runs are byte-identical.
